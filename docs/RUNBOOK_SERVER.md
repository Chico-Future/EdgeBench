# Server execution

Start a compatible inference server using that server's own installation instructions and the model's required chat template. Then use the API runner with the server's `/v1` base URL. The runner does not install, launch, or configure an inference server for you.

Check the model identifier, context window, generation settings, and authentication. The [API runbook](RUNBOOK_API.md) and [Home guide](../benchmarks/home/README.md) apply to local and remote servers.
