02 / EDGEBENCH-HOME

Seven ways to test an agent.

Different tasks expose different failure modes. Report family-level results alongside overall success.

01DGC

Device Grounding
and Control

Resolve a device reference and carry out the requested control.

02MSC

Multi-device Selection
and Control

Select the relevant devices and coordinate their actions.

03AIR

Ambiguity and
Intent Resolution

Decide when to act and when missing information requires clarification.

04FAR

Future Automation
Registration

Register future behavior without executing it immediately.

05DCR

Dialogue-context
Resolution

Use conversation context to resolve the current request.

06PMU

Personalized
Memory Use

Use relevant preferences and memory for the current task.

07REQ

Read-only
Environment Queries

Answer questions about the environment without changing its state.

03 / INTERFACES

Given the state.
Or asked to find it.

Two interfaces separate acting on supplied context from gathering information through interaction.

SG

State-Given

Relevant context is supplied to the model for a single response.

CONTEXT → RESPONSE → SCORE
SS

State-Seeking

The model begins with partial observations and uses tools to query and act.

OBSERVE ⇄ INTERACT → SCORE
