# Model logo sources

The leaderboard uses the official brand mark for each model family. Square variants are crops of the corresponding official artwork so they remain legible at leaderboard size; no marks are redrawn. All marks remain the property of their owners.

- Qwen (`qwen-icon.png`): cropped from the [official Qwen-72B logo asset](https://huggingface.co/Qwen/Qwen-72B/resolve/main/assets/logo.jpg).
- MiniCPM (`minicpm-icon.png`): blue emblem cropped from [OpenBMB's official MiniCPM logo](https://raw.githubusercontent.com/OpenBMB/MiniCPM/main/assets/minicpm_logo.png).
- DeepSeek (`deepseek-icon.png`): whale emblem cropped from [DeepSeek's official repository logo](https://raw.githubusercontent.com/deepseek-ai/DeepSeek-LLM/main/images/logo.png).
- Liquid AI / LFM (`lfm.png`): [official Liquid AI organization avatar](https://github.com/Liquid4All).
- GLM (`glm.png`): [official Z.ai organization avatar](https://github.com/zai-org), used as the provider mark for GLM models.
- MiMo (`mimo-wordmark.svg`): MiMo wordmark cropped by the SVG viewBox from [MiMo's official logo](https://mimo.xiaomi.com/mimo-v2-pro/assets/logo.svg).
- MiniMax (`minimax-icon.png`): symbol cropped from [MiniMax's official repository logo](https://raw.githubusercontent.com/MiniMax-AI/MiniMax-01/main/figures/MiniMaxLogo.png).
